回報問題

在 App 裡打開「設定 → 回報問題」，寫下發生什麼事，按下寄出。可以留聯絡方式（自願），我們才回得了你。會一起寄出的只有 App 版本、iOS 版本、手機型號、語言和幾項設定狀態，不含你的生日、人、地或事。

常見問題

「準」是什麼意思？

分三層。排盤：四柱、節氣、奇門每一局都逐局對照過原本的程式與公開的曆法程式庫，結果一致。讀法：能量分數和時辰順不順，是照乘時自己訂的規則算的（第 6 版），各派本來就沒有一致的讀法，這套規則也還沒被驗證過。合不合你：沒有可靠的證據說這類讀法能對上生活，所以請把它當參考。對帳頁可以看你自己的紀錄對得上多少。

為什麼能量有兩個數字？

「這天本身」只看那一天和那個月對你是補還是耗，每天都會變。「放進今年大環境」再加上流年和大運，這兩項整年或整十年都一樣，會把每天的分數一起往上或往下拉。兩個並列，你可以分開看「這天怎樣」和「今年整體怎樣」。小奇的表情和那句提示跟著「這天本身」。

晚上 11 點以後，為什麼算成明天？

傳統上一天從子時開始，子時是晚上 11 點到凌晨 1 點。乘時照這個規則：23:00 以後就換日，日柱算隔天，時辰盤也看明天那一張。所以晚上 11 點後，「現在」會出現在明天的盤上。如果你在 23:00 到 24:00 之間出生，你的日柱也會是隔天的那一柱。

時間用的是哪裡的時間？

用手機上的時區和鐘錶時間，沒有換算真太陽時。出生時間照你輸入的當地時間算。

不知道出生時間可以用嗎？

可以。關掉「知道出生時間」，乘時會少排時柱，也不排大運，所以「放進今年大環境」只加流年。其他功能照常。

排盤方法要選拆補還是置閏？

預設是拆補。兩種方法有三成多的時辰排出來不一樣，各有人用。不確定就用拆補；想換可以到「設定 → 排盤方法」。

怎麼回報問題？

在 App 裡打開「設定 → 回報問題」，寫下發生什麼事，按下寄出。只有你按下寄出時才會連網。想要我們回覆，記得留聯絡方式。

買過 Pro，換手機或重裝後怎麼拿回來？

用同一個 Apple 帳號登入，打開「設定 → 乘時 Pro → 恢復購買」。

怎麼取消訂閱？

訂閱由 Apple 管理。到 iPhone 的「設定 → 你的名字 → 訂閱」，選乘時 Pro 取消。要在這一期結束的 24 小時前取消，才不會續訂。買斷不會續訂。

怎麼刪除我的資料？

打開「設定 → 清除全部資料」，你的生日、人、事、地、回報紀錄和學過的課都會刪掉，不能復原。如果你在 AI 解讀填過 API key，把 key 的欄位清空就會從鑰匙圈刪掉。刪除 App 也會刪掉 App 裡的資料。我們沒有伺服器，所以沒有另一份要刪。

AI 解讀會把什麼送出去？

預設不用 AI。選「Apple 內建」時在手機上跑，不送出去。選「我的 API key」時，手機會直接把一份事實表送到你選的服務：程式算好的結果與理由、你寫下的那件事，有選對象的話加上他的名字與標籤，不含任何生日。AI 只把這份事實表改寫成白話，不會改結論。
