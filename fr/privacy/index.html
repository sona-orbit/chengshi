Politique de confidentialité

Chengshi n’a ni compte ni serveur à nous. Ce que vous saisissez reste sur votre iPhone. Voici dans quels cas l’app se connecte à Internet et ce qu’elle envoie.

L’app suit la langue de votre iPhone et existe en dix langues. Les captures de ce site proviennent de la version en chinois traditionnel.

Données sur votre téléphone

Votre date et heure de naissance, votre genre, les personnes que vous ajoutez, les lieux enregistrés, les dossiers d’affaires, vos anciennes questions, vos bilans, les modifications de vos éléments favorables, les leçons terminées et les réglages. Les conclusions des bilans et les suggestions d’éléments sont aussi calculées sur le téléphone. Ces données sont stockées dans le dossier de l’app et ne nous parviennent jamais. Elles sont incluses dans les sauvegardes de votre iPhone (iCloud ou ordinateur, selon les réglages de votre téléphone).

Localisation

Seul l’onglet « Lieux » l’utilise. L’app ne demande l’autorisation d’accéder à votre position que si vous choisissez votre position actuelle comme point de départ. Votre position sert à calculer les directions sur le téléphone et n’est envoyée nulle part.

Cartes et recherche de lieux

La recherche d’un lieu ou l’affichage de la carte dans « Lieux » utilise le service de cartographie d’Apple (MapKit) : le texte de votre recherche est envoyé à Apple pour obtenir des résultats, et les données cartographiques viennent d’Apple, conformément à sa politique de confidentialité.

Notifications

Le rappel du soir est une notification locale programmée sur le téléphone. Aucun serveur n’intervient. Vous pouvez le désactiver dans les réglages.

Annonces (version gratuite uniquement)

La version gratuite affiche une bannière Google AdMob tout en bas de la page « Demain » ; Pro n’affiche aucune annonce. Chengshi ne demande que des annonces non personnalisées, n’affiche pas de demande d’autorisation de suivi iOS et ne transmet jamais vos données de naissance, personnes, lieux, affaires ou bilans à l’annonce. Pour afficher l’annonce, Google reçoit les données nécessaires sur l’appareil et le réseau, comme l’adresse IP, le modèle de l’appareil, la position approximative et le fait que l’annonce ait été touchée ou non, conformément à sa politique de confidentialité. Dans l’UE et au Royaume-Uni, le formulaire de consentement de Google apparaît d’abord ; vous pouvez ensuite modifier votre choix dans Réglages → Choix de confidentialité des annonces.

Explications par l’IA (facultatives, désactivées par défaut)

Avec « Apple sur l’appareil », le modèle d’Apple fonctionne sur le téléphone et rien n’est envoyé. Avec « Mon API key », lorsque vous demandez une explication par l’IA, le téléphone envoie directement une fiche récapitulative au service d’IA choisi dans les réglages, sans passer par nous. Cette fiche contient les résultats calculés et leurs raisons (énergie, heures, directions, etc.), l’affaire que vous avez décrite et, si vous avez choisi une personne, son nom et les étiquettes que vous lui avez données. Elle ne contient la date de naissance de personne. Votre API key est stockée dans le Keychain d’iOS sur ce téléphone. Le service traite ce qu’il reçoit selon ses propres conditions.

Signaler un problème

Un rapport n’est envoyé que lorsque vous ouvrez Réglages → Signaler un problème et touchez « Envoyer ». Il contient ce que vous avez écrit, vos coordonnées si vous avez choisi de les donner, la version de l’app, la version d’iOS, le modèle de l’appareil, la langue et une ligne sur vos réglages (méthode de calcul du thème, version des règles, modification éventuelle de vos éléments favorables, nombre de bilans). Il est envoyé à notre service de collecte (Google Apps Script) et conservé dans notre feuille Google, uniquement pour résoudre les problèmes et vous répondre. Un identifiant aléatoire, créé lors de votre premier envoi, y est joint uniquement pour limiter le nombre de rapports envoyés par heure ; il n’est pas lié à votre identité. Vos données de naissance, personnes, lieux, affaires et bilans ne sont jamais envoyés.

Achats

Apple gère les achats et les abonnements Chengshi Pro. Nous ne voyons jamais vos informations de paiement ; l’app demande seulement à l’App Store si vous possédez Pro.

Ce que l’app n’utilise pas

Pas de compte, ni de SDK d’analyse ou de suivi. Rien de ce que vous saisissez dans l’app n’est partagé avec d’autres entreprises. Les annonces ne figurent que dans la version gratuite ; voir « Annonces » ci-dessus.

Supprimer vos données

Réglages → Effacer toutes les données supprime les données de l’app, sans possibilité de les récupérer. Videz le champ API key pour supprimer la clé. Supprimer l’app supprime aussi ses données. Pour faire supprimer un rapport envoyé, envoyez-en un autre pour nous le demander.

Ce site web

Ce site web (sona-orbit.github.io) utilise Google Analytics pour compter les visites et voir quelles pages sont consultées. Google Analytics utilise des cookies et reçoit les pages que vous consultez, le type de votre navigateur et de votre appareil, ainsi qu’une position approximative déduite de votre adresse IP. Cela concerne uniquement le site web, pas l’app. Vous pouvez le bloquer dans les paramètres de confidentialité de votre navigateur ou avec le module de désactivation de Google : tools.google.com/dlpage/gaoptout.

Contact

Pour toute question sur la confidentialité, utilisez Réglages → Signaler un problème dans l’app, ou écrivez à : sona.orbit.hi@gmail.com

Si cette politique change, cette page et la date ci-dessous seront mises à jour.
