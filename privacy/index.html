隱私權政策

乘時沒有帳號，也沒有我們自己的伺服器。你輸入的資料都存在你的 iPhone 上。下面逐項說明，App 什麼時候會連網、送出什麼。

存在手機裡的資料

你的生日、出生時間、性別、加的人、存的地點、事的資料夾、問過的紀錄、對帳的回報、喜用的更改紀錄、學過的課，以及各項設定。對帳的結論和喜用建議也在手機上算。這些存在 App 自己的資料夾裡，我們收不到。它們會跟著你的 iPhone 備份（iCloud 備份或電腦備份，照你手機的設定）。

位置

只有「地」會用到。你選擇用現在的位置當出發點時，App 才會詢問定位權限。位置只在手機上用來算方位，不會送出去。

地圖與地點搜尋

在「地」搜尋地點或看地圖時，用的是 Apple 的地圖服務（MapKit）：你輸入的搜尋字會送到 Apple 取得結果，地圖圖資也從 Apple 下載。這部分照 Apple 的隱私政策處理。

通知

每晚提醒是手機自己排的本機通知，不經過任何伺服器。可以隨時在設定裡關掉。

廣告（只有免費版）

免費版在「明天」頁最底部放一條 Google AdMob 的橫幅廣告；Pro 沒有廣告。乘時只要非個人化廣告，不跳 iOS 的追蹤授權，也不把你的生日、人、地、事或回報交給廣告。為了放廣告，Google 會收到顯示廣告需要的裝置與網路資料，例如 IP 位址、裝置型號、大概的位置和廣告有沒有被點，照 Google 的隱私政策處理。在歐盟和英國，第一次會先出現 Google 的同意表單，之後可以在「設定 → 廣告的隱私選項」改。

AI 解讀（選用，預設關閉）

選「Apple 內建」時，用 Apple 在裝置上的模型，在手機上完成，不送出去。選「我的 API key」時，你按下 AI 解讀，手機會直接把一份事實表送到你在設定裡選的那一家 AI 服務，不經過我們。事實表裡有：程式算好的結果與理由（能量、時段、方位等）、你寫下的那件事；如果有選對象，加上他的名字和你給的標籤。不含任何人的生日。你的 API key 存在 iOS 的鑰匙圈（Keychain），只留在這支手機。那家服務怎麼處理收到的內容，照它自己的條款。

回報問題

只有在你打開「設定 → 回報問題」並按下寄出時才會送出。內容是：你寫的描述、你自願留的聯絡方式、App 版本、iOS 版本、手機型號、語言，以及一行設定狀態（排盤方法、規則版本、有沒有手動改喜用、回報過幾筆）。這些送到我們自己的收件服務（Google Apps Script），存在我們的 Google 試算表，只用來處理問題和回覆你。另外會附一個 App 第一次寄回報時隨機產生的編號，只用來限制每小時能寄幾封，不連到你的身分。不會寄出你的生日、人、地、事或回報紀錄。

購買

乘時 Pro 的購買與訂閱由 Apple 處理。我們看不到你的付款資料，App 只向 App Store 確認你有沒有買。

沒有的東西

沒有帳號、沒有分析或追蹤套件，也不把你在 App 裡輸入的資料交給其他公司。廣告只在免費版，見上面「廣告」。

刪除資料

打開「設定 → 清除全部資料」就會刪掉存在 App 裡的資料，不能復原。AI 的 API key 可以把欄位清空來刪除。刪除 App 也會刪掉 App 裡的資料。寄過的回報如果想刪，在 App 裡再寄一封回報告訴我們。

本網站

本網站（sona-orbit.github.io）使用 Google Analytics 統計造訪人數，以及哪些頁面有人閱讀。Google Analytics 會使用 Cookie，並收到你瀏覽的頁面、瀏覽器與裝置類型，以及從 IP 位址推算的大概位置。這只適用於網站，與 App 無關。你可以在瀏覽器的隱私設定中封鎖，或安裝 Google 的停用外掛：tools.google.com/dlpage/gaoptout。

聯絡我們

對隱私有疑問，請在 App 裡「設定 → 回報問題」寄給我們，或寫信到： sona.orbit.hi@gmail.com
