サポート

よくある質問は以下にあります。見つからない場合は、アプリから報告してください。すべて目を通しています。

アプリはiPhoneの言語設定に合わせて表示され、10の言語に対応しています。このサイトのスクリーンショットは繁体字中国語版です。

問題を報告する

アプリで「設定 → 問題を報告」を開き、起きたことを書いて送信してください。返信が必要なら、連絡先を残せます（任意）。一緒に送られるのはアプリのバージョン、iOSのバージョン、端末のモデル、言語と一部の設定だけです。生年月日、人、場所、案件は送られません。

まだアプリを入れていない場合や、アプリが開かない場合は、メールでご連絡ください： sona.orbit.hi@gmail.com

よくある質問

スコアはどう計算していますか？

3つの段階があります。盤：四柱、節気、奇門遁甲の各盤を、元のプログラムと公開の暦ライブラリに1つずつ照らし合わせ、結果が一致することを確認しました。スコア：エネルギーは四柱推命の補いと消耗を見る方法に従います。時辰（刻）は奇門遁甲の回転式の盤を使い、八門を伝統的な分類で評価します。Chengshiのスコア計算法（第6版）がこれらを点数にし、アプリで項目ごとに表示します。振り返り：答え合わせのページで、提案が自分の記録とどのくらい合うかを見られます。

エネルギーの数字が2つあるのはなぜですか？

「その日自体」は日と月だけを見て、毎日変わります。「今年の中では」は流年と大運も加えます。この2つはそれぞれ1年または10年変わらず、毎日の数字を上下させます。並べて見ると、その日と今年の影響を分けて見られます。シャオチーの表情とひと言は、最初の数字に連動します。

23:00から翌日になるのはなぜですか？

伝統的には、1日は子の時辰（刻）、23:00から01:00に始まります。Chengshiもこれに従い、23:00から日柱が翌日に切り替わり、時辰（刻）のダイヤルには明日の盤が表示されます。そのため、23:00を過ぎると「今」は明日のダイヤルに表示されます。23:00から日付が変わるまでに生まれた場合、日柱も翌日のものになります。

どの時計を使いますか？

スマートフォンのタイムゾーンと時計の時刻を使います。真太陽時への換算はしません。出生時刻は、入力した現地時刻として扱います。

出生時刻がわからなくても使えますか？

はい。「出生時刻がわかる」をオフにしてください。時柱と大運は計算せず、「今年の中では」には流年だけを加えます。それ以外は使えます。

盤のページでは、どの日付を見られますか？

今日と明日は無料で、両日のすべての時辰（刻）を見られます。それ以外の日付はProで見られます。明日、相談の答え、時間を選ぶ、人から開くと、その時辰（刻）の盤が表示されます。

振り返りの結論はいつ出ますか？

最初は振り返りが14件たまったとき、次は30件、60件、その後は30件ごとです。振り返りのページ上部の進捗バーに、あと何日かが表示されます。各結論はその区切りまでの振り返りだけを使うため、毎日は変わりません。計算はスマートフォン上で行い、外部には送られません。

喜用神の提案で設定が勝手に変わりますか？

いいえ。「適用」をタップしたときだけ変わり、元に戻すこともできます。変更前と変更後の振り返りは分けて比較します。必要な振り返りの件数と差は、「設定 → 詳細 → 提案のしきい値」で変更できます。推奨値は30件、0.25段階、偶然の可能性のチェックはオンです。

無料版とProの違いは何ですか？

Proではレッスン6～17、今日と明日以外の日付の盤、振り返りの結論の全文と提案を見られます。無料版では、各結論の見出し、全体の一致率、最も一致した日の種類を見られます。それ以外の機能は同じです。Proには月額・年額のサブスクリプションと買い切りがあります。Proに広告はなく、無料版では明日のページの一番下に1つ表示されます。

無料版に広告はありますか？

明日のページの一番下に、Google AdMobのバナーが1つあります。Chengshiが求めるのはパーソナライズされていない広告だけで、トラッキングの許可を求める画面は表示しません。相談、回答、盤、レッスン、購入画面には広告がありません。Pro（月額、年額、買い切り）には広告がありません。

アプリは何語に対応していますか？

10言語です。繁体字中国語、簡体字中国語、英語、日本語、韓国語、スペイン語、ドイツ語、フランス語、ブラジルポルトガル語、ベトナム語に対応しています。iPhoneの言語に合わせて切り替わります。Chengshiだけ変更するには、iPhoneの「設定 → Chengshi → 言語」を開いてください。盤の天干、地支、門、星は伝統的な漢字表記のままです。タップすると、お使いの言語で説明が表示されます。

どの作盤方法を選べばいいですか？

初期設定は拆補（chaibu）です。置閏（zhirun）とは、約3分の1の時辰（刻）で盤が異なります。どちらも使われています。迷ったら初期設定のままで大丈夫です。「設定 → 詳細 → 作盤方法」で変更できます。

問題はどう報告しますか？

「設定 → 問題を報告」を開き、起きたことを書いて送信してください。アプリが通信するのは、送信をタップしたときだけです。返信が必要なら、連絡先を残してください。

Proを購入しました。新しいスマートフォンで復元するには？

同じApple Accountでサインインし、「設定 → Chengshi Pro → 購入を復元」を開いてください。

サブスクリプションを解約するには？

サブスクリプションはAppleが管理しています。iPhoneで「設定 → 自分の名前 → サブスクリプション」を開き、Chengshi Proを解約してください。現在の期間が終わる24時間前までに手続きしてください。買い切りは更新されません。

データを削除するには？

「設定 → すべてのデータを消去」を開いてください。生年月日、人、案件、場所、振り返り、レッスンの記録が削除され、復元できません。AIの説明用にAPI keyを入力した場合は、その入力欄を空にするとKeychainから削除されます。アプリを削除しても、そのデータは削除されます。サーバーはないため、別のコピーもありません。

AI機能は何を送信しますか？

AIは初期設定ではオフです。Appleの端末上のモデルを使う場合、スマートフォンの外には何も送られません。自分のAPI keyを使う場合は、計算した結果と理由、書いた案件、選んだ人の名前とタグをまとめた情報を、スマートフォンから選んだサービスへ直接送ります。生年月日は含まれません。AIはその情報をわかりやすい言葉に書き直すだけで、結論は変えられません。

Chengshi：あなたの奇門遁甲・時選びアドバイザー
Chengshiは伝統的な中国暦から盤を作り、公開している独自の採点方法で点数にします。予定を立て、振り返るためのアプリです。
