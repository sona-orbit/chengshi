앱은 iPhone의 언어 설정을 따르며 10개 언어로 제공돼요. 이 사이트의 화면 이미지는 중국어 번체 버전이에요.

문제 신고

앱에서 ‘설정 → 문제 신고’를 열고 무슨 일이 있었는지 적은 뒤 ‘보내기’를 탭하세요. 답장을 원하면 연락처를 남겨주세요. 선택 사항이에요. 앱 버전, iOS 버전, 기기 모델, 언어와 일부 설정만 함께 전송돼요. 출생 정보, 사람, 장소, 일은 전송되지 않아요.

자주 묻는 질문

점수는 어떻게 계산하나요?

세 단계예요. 반(盤): 사주, 절기, 모든 기문둔갑 국을 원본 프로그램과 공개 달력 라이브러리에 하나씩 대조했고 결과가 일치했어요. 점수: 에너지는 사주에서 보탬과 소모를 읽는 방식에 따르고, 시진은 기문둔갑 회전식 반(盤)과 팔문의 전통적 분류에 따라 살펴봐요. Chengshi의 점수 계산 방식(버전 6)이 이를 점수로 바꾸고, 앱에서 항목별로 보여줘요. 기록: 기록 화면에서 제안이 내 기록과 얼마나 일치하는지 볼 수 있어요.

에너지 숫자가 왜 두 개인가요?

‘그날 자체’는 그날과 그달만 보고 매일 바뀌어요. ‘올해 안에서’는 한 해나 10년 동안 그대로인 세운과 대운도 더해 매일의 수치를 올리거나 내려요. 두 숫자를 나란히 보면 그날과 올해를 따로 볼 수 있어요. 샤오치의 표정과 짧은 안내는 첫 번째 숫자를 따라요.

왜 23:00부터 다음 날로 보나요?

전통적으로 하루는 子 시진인 23:00부터 01:00까지의 시작 시점에 시작해요. Chengshi도 이에 따라 23:00부터 일주를 다음 날로 바꾸고, 시진 다이얼에 내일의 반(盤)을 보여줘요. 그래서 23:00 이후에는 ‘지금’이 내일 다이얼에 나타나요. 23:00부터 자정 사이에 태어났다면 일주도 다음 날의 일주예요.

어떤 시간을 사용하나요?

휴대폰의 시간대와 시계 시간을 사용해요. 진태양시로 바꾸지 않아요. 출생 시간은 입력한 현지 시간 그대로 사용해요.

출생 시간을 몰라도 쓸 수 있나요?

네. ‘출생 시간을 알아요’를 끄면 돼요. 그러면 Chengshi는 시주와 대운을 제외하고, ‘올해 안에서’에는 세운만 더해요. 다른 기능은 그대로 쓸 수 있어요.

반(盤) 화면에서 어떤 날짜를 볼 수 있나요?

오늘과 내일은 무료로 볼 수 있고, 두 날의 모든 시진을 볼 수 있어요. 다른 날짜는 Pro에서 볼 수 있어요. ‘내일’, 묻기 답변, ‘시간 고르기’, ‘사람’에서 열면 해당 시진의 반(盤)으로 이동해요.

기록 결론은 언제 나오나요?

처음은 14번 기록한 뒤, 다음은 30번과 60번, 그 뒤로는 30번마다 나와요. 기록 화면 맨 위의 진행 막대에서 며칠이 남았는지 볼 수 있어요. 각 결론은 해당 기준까지의 기록만 사용하므로 날마다 바뀌지 않아요. 휴대폰에서 계산하며 어디에도 전송하지 않아요.

희용신 제안이 설정을 저절로 바꾸나요?

아니요. ‘적용’을 탭할 때만 바뀌고, 다시 되돌릴 수 있어요. 변경 전후의 기록은 따로 비교해요. ‘설정 → 고급 → 제안 기준’에서 필요한 기록 수와 차이의 크기를 정할 수 있어요. 권장값은 기록 30번, 0.25단계, 우연 여부 확인 켜짐이에요.

무료 버전과 Pro는 무엇이 다른가요?

Pro에서는 6부터 17까지의 강의, 오늘과 내일 외 날짜의 반(盤), 기록의 전체 결론과 제안을 볼 수 있어요. 무료 버전에서는 각 결론의 제목, 전체 일치율, 가장 잘 맞는 날의 유형을 볼 수 있고 나머지 기능은 같아요. Pro는 월간 또는 연간 구독이나 일회성 구매로 이용할 수 있어요. Pro에는 광고가 없고, 무료 버전은 ‘내일’ 화면 맨 아래에 광고 하나가 나와요.

무료 버전에 광고가 있나요?

Google AdMob 배너 하나가 ‘내일’ 화면 맨 아래에 나와요. Chengshi는 개인 맞춤이 아닌 광고만 요청하고 추적 허용 요청은 표시하지 않아요. ‘묻기’, 답변, 반(盤), 강의, 구매 화면에는 광고가 없어요. Pro(월간, 연간, 일회성)에는 광고가 전혀 없어요.

앱은 어떤 언어를 지원하나요?

10개 언어를 지원해요. 중국어 번체와 간체, 영어, 일본어, 한국어, 스페인어, 독일어, 프랑스어, 브라질 포르투갈어, 베트남어예요. iPhone 언어를 따라가며, Chengshi의 언어만 바꾸려면 iPhone의 ‘설정 → Chengshi → 언어’를 여세요. 반(盤)의 천간, 지지, 문, 성은 전통 표기대로 한자로 남아요. 탭하면 선택한 언어로 설명을 볼 수 있어요.

어떤 반(盤) 방식을 선택해야 하나요?

기본값은 拆補(차이부)예요. 置閏(즈룬)을 쓰면 시진의 약 3분의 1에서 결과가 다르게 나오고, 두 방식 모두 사용돼요. 잘 모르겠다면 기본값을 유지하세요. ‘설정 → 고급 → 반(盤) 방식’에서 바꿀 수 있어요.

문제는 어떻게 신고하나요?

‘설정 → 문제 신고’를 열고 무슨 일이 있었는지 적은 뒤 ‘보내기’를 탭하세요. ‘보내기’를 탭할 때만 앱이 인터넷에 연결돼요. 답장을 원하면 연락처를 남겨주세요.

Pro를 구매했어요. 새 휴대폰에서 어떻게 다시 이용하나요?

같은 Apple 계정으로 로그인하고 ‘설정 → Chengshi Pro → 구매 복원’을 여세요.

구독은 어떻게 취소하나요?

구독은 Apple에서 관리해요. iPhone에서 ‘설정 → 내 이름 → 구독’을 열고 Chengshi Pro를 취소하세요. 현재 구독 기간이 끝나기 최소 24시간 전에 취소해야 해요. 일회성 구매는 갱신되지 않아요.

내 데이터는 어떻게 삭제하나요?

‘설정 → 모든 데이터 지우기’를 여세요. 출생 정보, 사람, 일, 장소, 기록, 강의 학습 내역이 삭제되며 복원할 수 없어요. AI 설명용 API key를 입력했다면 해당 입력란을 비우세요. 그러면 Keychain에서도 삭제돼요. 앱을 삭제해도 앱의 데이터가 삭제돼요. 저희는 서버가 없어 다른 사본도 없어요.

AI 기능은 무엇을 전송하나요?

AI는 기본적으로 꺼져 있어요. Apple의 기기 내 모델을 쓰면 휴대폰 밖으로 아무것도 나가지 않아요. 직접 입력한 API key를 쓰면 휴대폰이 선택한 서비스에 사실 요약을 바로 보내요. 계산된 결과와 이유, 작성한 일, 사람을 선택했다면 그 사람의 이름과 태그가 포함돼요. 출생 날짜는 포함되지 않아요. AI는 이 내용을 쉬운 말로 바꿔 쓸 뿐, 결론은 바꿀 수 없어요.

Chengshi: 나만의 기문둔갑 시간 길잡이
Chengshi는 전통 중국 달력으로 반(盤)을 만들고, 자체적으로 설명한 점수 계산 방식에 따라 점수로 바꿔요. 일정을 세우고 돌아보는 데 쓸 수 있어요.
