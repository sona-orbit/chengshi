개인정보 처리방침

Chengshi에는 계정도 자체 서버도 없어요. 입력한 내용은 iPhone에 남아요. 앱이 인터넷에 연결되는 경우와 보내는 정보를 아래에 설명해요.

앱은 iPhone의 언어 설정을 따르며 10개 언어로 제공돼요. 이 사이트의 화면 이미지는 중국어 번체 버전이에요.

휴대폰에 저장되는 데이터

생년월일과 태어난 시간, 성별, 추가한 사람, 저장한 장소, 일 폴더, 지난 질문, 기록, 희용신 변경 사항, 마친 수업과 설정이 저장돼요. 기록의 결론과 오행 제안도 휴대폰에서 계산해요. 이 데이터는 앱 전용 폴더에 저장되며 저희에게 전송되지 않아요. iPhone 설정에 따라 백업(iCloud 또는 컴퓨터)에는 포함돼요.

위치

‘장소’ 탭에서만 사용해요. 현재 위치를 출발점으로 선택할 때만 앱이 위치 권한을 요청해요. 위치는 휴대폰에서 방향을 계산하는 데 쓰이며 어디에도 전송되지 않아요.

지도와 장소 검색

‘장소’에서 장소를 검색하거나 지도를 보면 Apple의 지도 서비스(MapKit)를 사용해요. 검색어는 결과를 찾기 위해 Apple로 전송되고, 지도 데이터도 Apple에서 받아요. 이 과정에는 Apple의 개인정보 처리방침이 적용돼요.

알림

저녁 알림은 휴대폰에 예약되는 로컬 알림이에요. 서버를 거치지 않아요. ‘설정’에서 끌 수 있어요.

광고(무료 버전만)

무료 버전의 ‘내일’ 화면 맨 아래에는 Google AdMob 배너 광고가 하나 있어요. Pro에는 광고가 없어요. Chengshi는 개인 맞춤이 아닌 광고만 요청하고, iOS 추적 허용 메시지를 표시하지 않으며, 생년월일, 사람, 장소, 일, 기록을 광고에 제공하지 않아요. 광고를 표시하기 위해 Google은 IP 주소, 기기 모델, 대략적인 위치, 광고를 탭했는지 여부 등 필요한 기기 및 네트워크 정보를 받아요. 이 정보에는 Google의 개인정보 처리방침이 적용돼요. EU와 영국에서는 Google의 동의 양식이 먼저 표시돼요. 나중에 ‘설정 → 광고 개인정보 선택’에서 선택을 바꿀 수 있어요.

AI 설명(선택 사항, 기본적으로 꺼짐)

‘Apple 온디바이스’를 선택하면 Apple의 온디바이스 모델이 휴대폰에서 실행되며 아무것도 전송되지 않아요. ‘내 API key’를 선택하고 AI 설명을 요청하면, 휴대폰에서 ‘설정’에서 고른 AI 서비스로 정보 요약을 직접 보내요. 저희를 거치지 않아요. 여기에는 계산된 결과와 이유(에너지, 시간대, 방향 등), 작성한 일, 사람을 선택했다면 그 사람의 이름과 지정한 태그가 들어가요. 누구의 생년월일도 들어가지 않아요. API key는 이 휴대폰의 iOS Keychain에 저장돼요. 해당 서비스가 받은 정보는 그 서비스의 약관에 따라 처리돼요.

문제 신고

‘설정 → 문제 신고’를 열고 보내기를 탭할 때만 전송돼요. 작성한 내용, 제공하기로 선택한 연락처, 앱 버전, iOS 버전, 기기 모델, 언어와 설정 정보 한 줄(반(盤) 방식, 규칙 버전, 희용신을 변경했는지, 기록한 횟수)이 포함돼요. 이 정보는 자체 수집 도구(Google Apps Script)로 전송되어 저희 Google 스프레드시트에 보관돼요. 문제를 해결하고 답변하는 데만 사용해요. 처음 신고할 때 생성되는 무작위 ID도 첨부되지만, 시간당 보낼 수 있는 신고 건수를 제한하는 데만 쓰이며 신원과 연결되지 않아요. 생년월일, 사람, 장소, 일, 기록은 전송되지 않아요.

구매

Chengshi Pro 구매와 구독은 Apple이 처리해요. 저희는 결제 정보를 볼 수 없고, 앱은 App Store에 Pro 보유 여부만 확인해요.

앱에 없는 것

계정도, 분석 또는 추적 SDK도 없어요. 앱에 입력한 내용은 다른 회사와 공유하지 않아요. 광고는 무료 버전에만 있어요. 위의 ‘광고’를 참고해요.

데이터 삭제

‘설정 → 모든 데이터 지우기’를 선택하면 앱의 데이터가 삭제되며 되돌릴 수 없어요. API key는 입력란을 비우면 삭제돼요. 앱을 삭제해도 앱의 데이터가 삭제돼요. 보낸 신고를 삭제하고 싶다면 신고를 하나 더 보내 요청해 주세요.

이 웹사이트

이 웹사이트(sona-orbit.github.io)는 방문 횟수와 읽은 페이지를 확인하기 위해 Google Analytics를 사용해요. Google Analytics는 쿠키를 사용하며, 방문한 페이지, 브라우저와 기기 종류, IP 주소에서 파악한 대략적인 위치를 받아요. 이는 웹사이트에만 해당하며 앱에는 적용되지 않아요. 브라우저의 개인정보 설정이나 Google의 차단 부가기능으로 막을 수 있어요: tools.google.com/dlpage/gaoptout.
